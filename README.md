# フラッシュことば

「フラッシュことば」は、ひらがな・ことばの認識力を育てるための  
子ども向けフラッシュ学習ゲームです。

一瞬だけ表示される文字や単語を見て、  
「なんて書いてあったか？」を答えることで、  
視覚的な認識力・集中力・語彙力を楽しく伸ばせます。

---

## 🎮 できること

- 任意のことばを入力して出題（2人用・先生用モード）
- 難易度を選んで表示時間を調整
- ひらがな単語リストからランダム出題（1人学習用モード）
- 文字数ごとの学習（1〜6文字以上）
- 拗音・濁音・半濁音・短文にも対応

---

## 🧠 対象

- 小学1〜2年生向け
- ひらがな・カタカナを学習中の子ども
- 読みの練習・語彙トレーニング・授業・家庭学習におすすめ

---

## 📂 ファイル構成

```text
index.html
words-hiragana1.js        // 1文字
words-hiragana2.js        // 2文字
words-hiragana3.js        // 3文字
words-hiragana4.js        // 4文字
words-hiragana5.js        // 5文字
words-hiraganaSentences.js // 短文
README.md

▶ 使い方
index.html をブラウザで開く
問題を入力するか、ひとり学習用のボタンを選ぶ
難易度を選択
「出題」を押す
表示された文字を覚えて答える

✨ 特徴
フォント：Kosugi Maru（子ども向けで読みやすい）
Webフォント使用で環境差なく表示
教育現場・家庭学習・ICT教材に活用可能

🛠 開発目的
このアプリは、
「ひらがな・ことばを“楽しく・テンポよく”学べる教材」を目標に制作しました。
入力型と自動出題型の両方に対応し、
教師・保護者・子どもが使いやすい設計を意識しています。
